# Обновление вручную

Здесь лежат подписанные обновления клиента. Обычно игра качает их сама. Ручная установка нужна, если авто-обновление не проходит: провайдер режет соединение, мешает антивирус, или сервер обновлений недоступен.

## Что скачать

Из папки `updates/win32/`:

* `update.gcup`
* `update.gcup.sig`

Нужны **оба** файла. Без `.sig` игра молча проигнорирует обновление.

Качайте кнопкой **Download raw file**. Если сохранить страницу целиком, файл будет битым.

## Куда положить

В корень игры, туда же, где лежит `csgo.exe`.

```
C:\Games\csgo legacy\
├── csgo.exe
├── update.gcup          <- сюда
├── update.gcup.sig      <- и сюда
├── bin\
└── csgo\
```

Не в `csgo\`, не в `bin\`, не в `csgo_gc\`. Только рядом с `csgo.exe`.

## Как применить

1. Полностью закройте игру.
2. Положите оба файла рядом с `csgo.exe`.
3. Запустите `csgo.exe`. Игра проверит подпись и подготовит файлы. Оба файла после этого пропадут, так и должно быть.
4. Закройте игру.
5. Запустите `csgo.exe` ещё раз. Вот теперь обновление применилось.

Второй запуск обязателен: файлы подменяются до загрузки игры, поэтому подготовленное на первом запуске встаёт на место только на следующем.

## Как проверить, что обновилось

* В `updates/win32/version.txt` указана актуальная версия.
* В главном меню пропадёт красная полоса «Your Client Needs To Update».

## Если не получилось

**Файлы пропали, но версия прежняя.** Подпись прошла, обновление подготовлено. Запустите игру ещё раз.

**Файлы остались лежать на месте.** Игра их не нашла. Проверьте:

* лежат ровно рядом с `csgo.exe`, а не в подпапке;
* имена не изменились. Браузер часто сохраняет как `update (1).gcup`, такое имя не подходит;
* оба файла на месте, не только `.gcup`.

**Хочу видеть, что происходит.** Запустите игру с параметром `-console` и смотрите строки, которые начинаются с `[Update]`.

**Написало `manual bundle signature INVALID`.** Файл повреждён при скачивании или взят не отсюда. Игра удалит его сама. Скачайте заново, желательно без прокси и VPN, которые пережимают трафик.

## Проверка целостности (необязательно)

В `manifest.txt` лежит строка `sha256=` для бандла. Сверить в PowerShell:

```powershell
Get-FileHash .\update.gcup -Algorithm SHA256
```

Значения должны совпасть. Если нет, файл скачался не полностью.

## Безопасность

Каждый бандл подписан ключом Ed25519, а публичный ключ вшит в игру. Подменить файл посторонним не выйдет: подпись не сойдётся, и игра его удалит.
